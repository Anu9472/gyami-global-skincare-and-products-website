# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public GitHub issue. Use GitHub's
private vulnerability reporting for this repository, or contact the repository
owner through a private channel with a concise reproduction, impact, and any
suggested mitigation.

Please do not access customer data, place live orders, alter records, or disrupt
service while validating a report. We will acknowledge a good-faith report,
investigate it, and coordinate remediation before public disclosure.

## Supported release line

Security fixes are applied to the current `main` branch and should be deployed
through the documented release process.
